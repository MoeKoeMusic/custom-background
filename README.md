# MoeKoe 自定义背景插件 V2

## 功能介绍

这是一个为 MoeKoe Music Library 页面开发的自定义个人背景和歌单封面插件。

### 主要功能
- 🖼️ 在个人背景右上角添加上传按钮，点击可更换背景图片
- 📷 在每个歌单封面右上角添加上传按钮，点击可更换封面图片
- 💾 自动保存设置到本地存储
- 🔄 页面刷新后自动恢复自定义图片

## 安装方式

### 方式一：软件内自动安装（推荐）

适用场景：插件已上架到 MoeKoe 插件市场。

1. 打开 `设置 -> 插件管理`
2. 切换到 `插件市场`
3. 搜索插件并点击 `安装`
4. 安装完成后刷新插件列表或重启应用

### 方式二：GitHub 手动下载安装

1. 从 GitHub 下载本项目源码（`Code -> Download ZIP`）
2. 解压后找到目录：`plugins/extensions/custom-background`
3. 安装方式二选一：
4. 复制文件夹到 MoeKoe 插件目录（`plugins/extensions`），然后在插件管理中刷新
5. 或将该文件夹打包为 zip，在 `设置 -> 插件管理 -> 安装插件` 中选择 zip 安装

## 使用方法

1. 安装插件后，访问 MoeKoe Music 的个人中心页面
2. 在个人背景图片的右上角会出现 🖼️ 按钮
3. 在每个歌单封面的右上角会出现 📷 按钮
4. 点击对应按钮选择本地图片文件即可替换
5. 图片会自动保存，下次访问时会自动恢复

## 管理设置

- 点击浏览器工具栏中的插件图标可以打开设置面板
- 在设置面板中可以清除所有自定义设置

## 支持的图片格式

- JPG/JPEG
- PNG  
- GIF
- WebP
- BMP

## 注意事项

- 图片文件会转换为 Base64 格式存储在浏览器本地
- 建议使用文件大小适中的图片以避免性能问题
- 清除数据会导致自定义设置丢失

## 技术实现

- 使用 Chrome Extension Manifest V3
- 通过 FileReader API 读取本地图片文件
- 使用 localStorage 保存图片数据
- 通过 MutationObserver 监听页面变化并自动添加按钮
